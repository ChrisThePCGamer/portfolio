# Christopher Pineda — Portfolio

Personal portfolio for internship applications: BS Computer Science, Angeles University Foundation.

Featured project: **A.S.E.A.**, a transformer-based classifier (mBERT) that detects Philippine SMS scams written in code-switched Tagalog–English.

## About the site

- A single self-contained `index.html` with all CSS, JavaScript, images, and the CV embedded. There is no build step and no dependencies.
- Frosted-glass UI, scroll-reveal and pointer-reactive animations, and a responsive layout from 360px phones to wide desktops.
- Respects `prefers-reduced-motion`.

To view it, open `index.html` in a browser.
